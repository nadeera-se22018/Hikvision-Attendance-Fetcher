Hikvision Attendance Fetcher - User Guide

Step 1: Please ensure Java Runtime Environment (JRE) version 21 or higher is installed on your PC (available at Oracle Java Downloads) as it is required to run the application.

Step 2: Extract the provided folder containing 'HikvisionAttendance.exe' and 'config.properties' to your Desktop or a preferred location.

Step 3: Ensure both the '.exe' file and the 'config.properties' file ALWAYS remain in the same folder.

Step 4: Right-click the 'config.properties' file, open it with Notepad, and update the device IP, username, and password to match your fingerprint terminal. Save and close.

Step 5: Double-click 'HikvisionAttendance.exe' to launch the application. (Note: Previously fetched records will load automatically even if you are offline).

Step 6: To fetch new data, select your desired 'Start Date' and 'End Date' using the date selectors at the top.

Step 7: Click the "Fetch Attendance" button. The app will securely connect to the terminal and download the logs.

Step 8: To save the data for payroll or HR purposes, click the "Export to Excel" button, choose your save location, and save the .xlsx file.
